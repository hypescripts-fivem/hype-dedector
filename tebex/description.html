Put real security on your server's doors. Place walk-through metal detectors at malls, banks, hospitals and courthouses straight from an in-game admin panel. When a player carrying a weapon walks through, the gate turns red, beeps for everyone nearby and alerts police and security. Officers can also search people by hand with a handheld detector. In line with roleplay rules, the result only ever says "metal detected", never what was found.

Walk-Through Detectors Place as many detector gates as you like. Admins stand where the gate should go, face the way people walk through and click Use my position. The prop is spawned only for players nearby and sits on the floor automatically.
Reliable Pass Detection Each gate has its own trigger box that turns with the prop, so walking past the side never sets it off. The path between checks is traced as well, so sprinting through can't skip the scan. Standing inside the gate triggers it once, and vehicles are ignored.
Server Side Scan The client only reports which gate it walked through. Distance, cooldown, job and the player's whole inventory are checked on the server, so the result can't be faked from the client.
Roleplay Friendly Results Alerts, notifications, logs, the admin panel and Discord only say "metal detected". Item names, categories and amounts are never sent to anyone or stored anywhere, not even in the database.
Metal Categories Firearms, knives and melee weapons, explosives and ammunition come ready, and each gate picks which ones it reacts to. Add exact item names or patterns such as ^weapon_, and keep non-metal items like bats or flashlights out of it. Upper and lower case item names both match.
Light & Sound The gate lights up red with an alarm beep when it finds metal and green when the player is clean, for everyone around it. Colors, range, duration and sounds are all configurable.
Police & Security Alerts Alarms go to on-duty players in the jobs you choose, with a notification and a temporary map blip. The alert is a function in the config, so you can hook it into ps-dispatch, cd_dispatch, core_dispatch or your own dispatch, and examples are included.
Alerts Per Detector Turn police alerts on or off for each gate from the admin panel. A gate with alerts off still beeps red and logs the alarm, which is ideal for busy entrances or gates that should only deter.
Job Exemptions Police and security walk through with a green light while on duty. A config hook lets you add your own exceptions, for example a weapon license.
Hand Detector Officers search a player through ox_target or qb-target, or by using the item. The searcher walks around the player with the detector in hand while the player holds their hands up, then gets "metal detected" or "clean", and everyone nearby hears the beep. Required jobs, the required item, duration, distance and animations are configurable.
In-Game Admin Panel A modern panel with an overview of alarms today and this week, a 7 day chart, the busiest gates and the latest alarms. Create, edit, teleport to, enable, disable and delete detectors without touching a file.
Alarm Logs Every alarm is logged with the player and the gate. Filter the logs per detector, and old logs are removed automatically after the number of days you set in the panel.
Secure Discord Logs Alarms and admin actions can be sent to a Discord webhook. The webhook lives in a server only config file that is never sent to players, so it can't be read from the game.
Prop Placement Tool Admins can line the hand detector up in the hand with a live in-game tool and copy the exact position and rotation into the config.
Wide Compatibility Detects ESX, QBCore and Qbox automatically, with no extra core resource needed. Reads ox_inventory, qs-inventory, codem-inventory, tgiann-inventory and every inventory that keeps the framework's item list, ESX loadouts included. Notifications work with ox_lib, okokNotify or ps-ui. The framework and module bridges are left open so you can adapt them in minutes.
Highly Configurable Adjust categories, items, alert jobs, the alert itself, exempt jobs, trigger box size, cooldown, light, sounds, the hand detector's rules and animations, commands and much more. English and Turkish locales are included and new languages can be added easily.
